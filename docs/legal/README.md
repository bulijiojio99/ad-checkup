# 法律文件维护说明（给维护者看，不在网页上展示）

`terms.md`（使用协议，含免责声明）和 `privacy.md`（隐私政策）会被打包进网页，在 `#/terms`、`#/privacy` 页面展示。修改这两个文件就会同步修改网页内容。

## 正式上线前必须完成

1. **请律师审阅。** 这两份文件是按中国《个人信息保护法》《民法典》的常见要求起草的草案，不构成法律意见。如果运营主体不在中国大陆（例如在日本），还要同时考虑运营地的法律（如日本《个人信息保护法》），以及向中国境内用户提供服务时的境外适用问题。
2. **填写所有【】占位符：** 运营者名称、联系方式、适用法律、管辖法院或仲裁机构、响应时限。
3. **文件内容必须和代码行为一致。** 每次增加收集数据或对外发送数据的功能，都要先改隐私政策；隐私政策里写着“尚未开放”的功能，代码里不能提前收集。

## 设计原则（为什么这么写）

- **本工具不收集任何数据，也不联网。** 网页的 `connect-src` 固定为 `'none'`，仓库里没有服务端代码。以后如果增加任何联网或收集数据的功能，必须让用户单独勾选、默认不勾选，不能写成“使用即同意”（《个人信息保护法》第十六条）。
- **免责条款要显著提示（加粗）。** 《民法典》第四百九十六条要求提供格式条款的一方，对免除或减轻其责任的条款作出提示和说明；第五百零六条规定，因故意或重大过失造成对方财产损失的免责条款无效，所以协议保留了这一例外。
- **用词要准确。** 我们做的是“校准统计参数”，不是“训练大模型”，文件里不要混用。
