# 投流体检

上传亚马逊、抖音（巨量千川）、小红书（聚光 / 乘风）导出的广告报表，找出**有统计依据的低效花费**：哪些搜索词该否定、哪些计划或素材该止损、哪些值得加预算。

- **报表不出浏览器**：所有计算在本地完成。正式版页面设置了 `connect-src 'none'` 安全策略，技术上无法向任何服务器发送数据。
- **每条结论都有依据**：告诉你“要不亏需要多少转化率、它实际多少、这种情况是运气差的概率有多大”。
- **即用即分析，不收集数据**：没有任何收集、上传或保存报表数据的功能。
- **数据不够就说不够**：点击太少的词标为“待观察”，并告诉你还需要多少点击才能判断，不会冤枉好词。

## 支持的报表

| 平台 | 报表 | 状态 |
|---|---|---|
| 亚马逊 | 商品推广搜索词报告（英文表头，兼容新版 API 字段名） | 表头按公开资料整理，待真实文件逐列核对 |
| 抖音 · 巨量千川 | 搜索词 / 关键词报表；计划 / 素材 / 商品报表（含全域推广） | 测试版：官方帮助中心需登录，表头未核实 |
| 小红书 · 聚光 / 乘风 | 关键词 / 搜索词报表；计划或笔记报表（电商）；笔记种草报表（按互动） | 测试版：同上 |

识别不准时，可以在页面上手动指定每一列对应什么。欢迎提交脱敏后的真实报表，帮助校准表头。

## 怎么判断的

1. **参照线**：填写售价和成本，算出保本 ACoS（亚马逊）或保本 ROI（抖音、小红书，考虑退货率）；也可以直接填目标值，或用账户平均水平作参照。
2. **逐行检验**：每单最多可花的广告费 = 客单价 × 参照 ACoS；保本所需转化率 = 点击单价 ÷ 每单最多可花的广告费。
   - 有点击数据：二项分布检验。“如果它其实能保本，观察到这么少的订单，概率有多大？”
   - 没有点击数据（如全域推广素材报表）：按花费做泊松检验。
   - 种草笔记：按互动数和平均互动成本做泊松检验（一次点击可能产生多个互动，不满足二项分布前提）。
3. **分档**：概率低于 5% 且通过多重比较校正（Benjamini–Hochberg，对离散数据做了 Tarone 式改进）为“确定低效”；5%–20% 为“疑似”；数据不够为“待观察”。
4. **词根分析**：把搜索词拆成词累计，找出在多个搜索词里累计亏损的词根，适合加否定词组。
5. **相关性粗判**：搜索词里每个词都出现在产品描述里才算“相关”。相关但不出单的词建议先降价、查 Listing，而不是否定。最终可复制提示词交给 DeepSeek / Kimi / ChatGPT 判断。

防止误判的几道保险：

- **客单价分层估计**：一行的客单价按“自己的订单 → 所在组 → 全账户”加权估计，订单越少越靠近上一层，不会因为套用账户平均客单价而冤枉高客单价的词。
- **合理的转化率上限**：保本所需转化率高得不现实时（超过同组平均的 3 倍，最高 50%），按这个上限检验。只点了一两次的贵词不会仅凭“单次点击太贵”被判死刑。
- **以实际成交兜底**：按自己的实际成交已经达到参照线的行，不会被判为低效；没有达到的，不会被判为优秀。
- **互动成串出现**：一个用户可能既点赞又收藏，种草笔记的检验按离散度 4 做保守校正。
- **净成交口径**：千川的“净成交”只扣支付后 1 小时内的秒退，仍按含退货的保本线比较，不会把亏损计划判成赚钱。
- **只有关键词的报表**：建议暂停或降价，而不是“否定”自己买的关键词。

验证：

- `tests/simulation.test.ts`：刚好保本的词被误判为亏损的概率不超过 5%；在 60 个模拟账户、上万个词上，“确定低效”一档里真正赚钱的词占比不超过 10%。
- `tests/regressions.test.ts`：独立代码审查发现的 11 个问题（净成交口径、客单价、合计行识别、关键词报表、互动离散度、素材与计划合并、日月顺序、欧洲数字格式等），每个都有对应的回归测试。

放到自己网站上的部署说明见 [docs/integration.md](docs/integration.md)。

## 本地运行

```bash
npm install --legacy-peer-deps
npm run dev        # 开发模式
npm test           # 单元测试 + 模拟验证
npm run build      # 生成 dist/，可直接部署到任何静态托管
```

命令行版（之后的 AI 助手插件版会调用它）：

```bash
npm run build:cli
node dist-cli/ad-checkup.mjs 报表.csv --platform amazon --price 45.99 --cost 14 --fba 7.2 --referral 15 --product "产品标题和卖点"
node dist-cli/ad-checkup.mjs 千川.xlsx --platform douyin --price 89 --cost 28 --shipping 4 --platform-pct 5 --return-rate 35 --negatives 否定词.csv
```

## 局限

- 结论基于历史数据，不是对未来效果的保证。
- 亚马逊批量上传否定词需要广告活动 ID，目前导出的是按名称列出的清单。
- 抖音、小红书的表头需要用真实导出文件校准。
- 相关性判断是字词比对的粗判，可能把“相关但用词不同”的词判为部分相关。
